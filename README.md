# Narottam Sharan – Creative Video Editor Portfolio

A premium portfolio website built with React to showcase high-retention video editing projects, commercial work, and creative expertise.

## Features

- Premium Apple-inspired dark UI
- Fully responsive (Desktop, Tablet & Mobile)
- Smooth scrolling
- Interactive project gallery
- Short-form & Long-form categories
- Embedded YouTube project previews
- Case-study style project pages
- About section
- Testimonials
- Contact form with EmailJS
- Optimized performance and SEO

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis
- EmailJS

## Installation

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

Preview:

```bash
npm run preview
```
